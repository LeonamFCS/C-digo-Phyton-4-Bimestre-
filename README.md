# Código Python - 4º Bimestre

Este repositório foi criado para armazenar e organizar as atividades, exercícios práticos e códigos desenvolvidos em Python durante o 4º Bimestre.

## Projetos Incluídos

* **Quiz Tech CEJO/SENAI:** Um jogo interativo de perguntas e respostas de múltipla escolha criado para testar conhecimentos em tecnologia e programação Python.

## Tecnologias Utilizadas

* Python 3
* IDLE (Ambiente de Desenvolvimento Integrado do Python)
